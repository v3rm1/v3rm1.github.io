Current research

Hierarchical Coordination in Multi-Agent Reinforcement Learning

Ongoing — details after publication

How should a team of learning agents organise itself when no single agent sees the whole picture and payoffs arrive only after long delays? This PhD project designs structured, hierarchical multi-agent RL architectures in which agents coordinate in sub-teams, and compares them against established flat MARL baselines. The emphasis is on scaling to larger teams, robustness to partial observability, and honest evaluation across many random seeds with statistically sound aggregate metrics.

Multi-agent RL Reinforcement learning Hierarchical planning Sequential decision-making Experimental design & robust evaluation JAX Python

GPU-Accelerated Simulation for Multi-Agent Learning

Ongoing — details after publication

Learning agents need millions of interactions, so the simulator is often the bottleneck. This project builds fully vectorised, JIT-compiled simulation environments in JAX, so that thousands of scenarios step in parallel on a single GPU, with a validation suite to check the simulated dynamics behave plausibly.

Simulation & agent-based modelling JAX Multi-agent RL Experimental design & robust evaluation Python

JAX Library of Multi-Agent RL Algorithms

Ongoing

An environment-agnostic library of cooperative multi-agent RL algorithms written in JAX, covering trust-region actor-critic, value-decomposition and hierarchical methods behind a common interface, so new environments and algorithms can be swapped in without rewriting training code.

Cognitive Modelling: Basic Principles and Methods

Assignments and Project work for the Cognitive Modelling course offered under the MSc AI programme at the University of Groningen. We attempt to model an ACT-R (Adaptive Control of Thought - Rational) agent to study how the model performs in a timing experiment based on the experiment carried out by Jazayeri and Shadlen. Temporal learning is modelled as a Bayesian Process with prior experiences affecting the perception of future temporal signals. The model is built in Python using the ACT-R theoretical framework. The experiment alters previous work by utilising highly skewed base distributions and removing participant feedback. The model depicted clearly the expected skew in outputs discussed in the experimentation section.

Deep Learning: Reinforcement Learning with Confidence Estimation

Project work for the Deep Learning course offered under the MSc AI programme at the University of Groningen. Devised an unconventional method of including confidence estimation in a reinforcement learning system. The system outputs action/confidence pairs, where the confidence represents the system's best guess as to the probability of the action resulting in a successful outcome. The confidence is trained by altering the reward function such that the reward is a function of both the real value of the action and the confidence given. Tested using Proximal Policy Optimisation (PPO) on the Atari Pong environment. Two approaches tested: 1. Proximal Policy Optimisation (PPO) 2. PPO with Confidence Estimation The model achieves accurate confidence estimation when the estimated confidence equals the probability value returned by the Softmax layer.
